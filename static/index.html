NETFLIX

Static Component Library

This folder contains static HTML/Tailwind versions of the Netflix Clone components. Each component is available as a standalone HTML file for easy reference and future work.

Hero Component

Full-width hero section with video background, title, description, and action buttons.

Button Component

Reusable button styles with primary, secondary, and ghost variants.

Movie Card Component

Interactive movie/TV show card with hover effects and metadata.

Navbar Component

Fixed navigation bar with logo and side menu functionality.

Search Component

Search input with icon and focus states.

Carousel Component

Horizontal scrolling carousel for movie/TV show rows.
